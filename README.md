# AI 深度长文

获取 AI热报 编辑团队撰写的 AI 深度文章与评述全文。用于“有没有写得更深一点的文章”“关于 XX 的长文/评述”“帮我把某件事的完整分析拿来”“有什么可以慢读的 AI 内容”等需要成篇论述而非快讯条目的请求。与 ai-news 的区别：ai-news 给的是几十字的新闻条目，本 skill 给的是完整正文。

## 安装

```bash
skillhub install ai-editorial
```

也可以直接把 `SKILL.md` 放进你的 skill 目录——它是完整的 skill 正文，
里面写明了 Base URL、请求头和参数约定。

## 文件

- `SKILL.md` — skill 正文（frontmatter 的 `name` / `description` 即安装入口）
- `_meta.json` — 发布元数据（slug / version / displayName / summary / license / edition）
